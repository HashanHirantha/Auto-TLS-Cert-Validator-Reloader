## Milestone 1 — CRD & API Types (Foundation)

### F-001: TLSCertWatch Custom Resource Definition

**Priority:** P0 — Must Have  
**Status:** 🔲 Planned  
**Owner:** —

**Description:**  
Define the `TLSCertWatch` CRD (Group: `tls.certreloader.io`, Version: `v1alpha1`).
The Spec captures *what* to watch and *what* to reload; the Status captures health.

**Spec Fields:**

```yaml
apiVersion: tls.certreloader.io/v1alpha1
kind: TLSCertWatch
metadata:
  name: my-app-tls
  namespace: default
spec:
  # Reference to the Secret or ConfigMap holding the TLS cert
  certificateRef:
    kind: Secret            # Secret | ConfigMap
    name: my-app-tls-secret
    namespace: default      # optional, defaults to CR namespace
    certKey: tls.crt        # key inside the Secret holding the cert PEM
    keyKey: tls.key         # key inside the Secret holding the private key PEM
    caKey: ca.crt           # optional — CA bundle key

  # Validation policy
  validation:
    checkExpiry: true
    expiryThresholdDays: 30     # warn/reload if cert expires within N days
    checkChain: true            # validate the full chain up to CA
    checkHostnames:             # optional SAN / CN match list
      - "*.example.com"
      - "api.example.com"

  # What to restart when the cert is invalid or rotated
  targets:
    - kind: Deployment
      name: my-app
      namespace: default
    - kind: StatefulSet
      name: my-db
      namespace: default

  # How often to re-check (in addition to Secret watch events)
  checkIntervalMinutes: 60

  # Reload strategy
  reloadStrategy: RollingRestart   # RollingRestart | Annotation (patch restart annotation)

  # Optional: pause reconciliation
  paused: false
```

**Status Fields:**

```yaml
status:
  conditions:
    - type: CertificateValid
      status: "True"
      lastTransitionTime: "2024-10-01T12:00:00Z"
      reason: Valid
      message: "Certificate is valid, expires in 90 days"
    - type: ReloadRequired
      status: "False"
  lastCheckedAt: "2024-10-01T12:00:00Z"
  certificateExpiry: "2025-01-01T00:00:00Z"
  certificateFingerprint: "sha256:abcdef..."
  observedGeneration: 3
```

**Acceptance Criteria:**

- [ ] `make manifests` generates valid CRD YAML
- [ ] `kubectl apply -f` installs the CRD without errors
- [ ] `kubectl get tlscertwatches` returns an empty list
- [ ] Kubebuilder markers produce correct OpenAPI validation (e.g., enum for `reloadStrategy`)

### F-005: Reconciliation Loop Logic

**Priority:** P0  
**Status:** 🔲 Planned

```
Reconcile(ctx, req) →
  1. Fetch TLSCertWatch CR  (NotFound → return, no requeue)
  2. Check if paused          (paused → return, no requeue)
  3. Fetch referenced Secret
  4. Parse & validate cert    (→ F-006)
  5. Compare fingerprint to status.certificateFingerprint
  6. If changed or invalid → trigger reload (→ F-007)
  7. Update CR status conditions
  8. Requeue after spec.checkIntervalMinutes
```

- [ ] Idempotent — repeated reconcile produces the same result
- [ ] Errors surface as Kubernetes Events on the CR
- [ ] Status conditions updated atomically

## Milestone 3 — Certificate Validation Engine

### F-006: TLS Certificate Parsing & Validation

**Priority:** P0  
**Status:** 🔲 Planned

**Implementation (`internal/cert/validator.go`):**

| Check               | Go API                                       |
| -------------------- | -------------------------------------------- |
| PEM decode           | `encoding/pem.Decode`                        |
| X.509 parse          | `crypto/x509.ParseCertificate`               |
| Expiry               | `cert.NotAfter.Before(time.Now().Add(threshold))` |
| Chain verification   | `cert.Verify(x509.VerifyOptions{…})`         |
| SAN / CN match       | `cert.VerifyHostname(host)`                  |
| Fingerprint (SHA-256)| `sha256.Sum256(cert.Raw)`                    |
| Key ↔ Cert match     | Compare public key from cert and private key |

- [ ] Returns structured `ValidationResult` with per-check pass/fail
- [ ] Unit tested with self-signed certs (generated in test)
- [ ] Handles multi-cert PEM bundles (intermediates)
